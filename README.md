## 📌 About the Project

**SchoolLearner** is an educational web project focused on improving the learning experience through digital technology.

The goal is to create a simple and accessible platform that helps learners access educational content and supports a more organized learning experience.

This project is part of my journey as a developer, where I explore web development, problem-solving, and practical software implementation.
